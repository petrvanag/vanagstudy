# Заявки с сайта → Telegram

Форма на сайте отправляет заявку на маленький сервер (Cloudflare Worker, бесплатно),
а он пересылает её ботом вам в Telegram. Посетителю не нужен Telegram, заявка не теряется.

## 1. Бот (5 минут)

1. В Telegram откройте @BotFather → `/newbot` → придумайте имя, например `VanagStudy заявки`.
   BotFather пришлёт **токен** — длинную строку вида `123456:ABC...`. Никому её не показывайте.
2. Напишите своему новому боту любое сообщение (иначе он не сможет вам писать).
   Если хотите, чтобы заявки видели и преподаватели, создайте группу и добавьте бота туда.
3. Узнайте **chat_id**: откройте в браузере
   `https://api.telegram.org/bot<ТОКЕН>/getUpdates` и найдите `"chat":{"id": ...}`.
   Для личного чата это обычное число, для группы — число с минусом.

## 2. Worker (10 минут)

Нужен бесплатный аккаунт на dash.cloudflare.com. Затем в этой папке:

```bash
npx wrangler login
npx wrangler secret put BOT_TOKEN
npx wrangler secret put CHAT_ID
npx wrangler deploy
```

`secret put` спросит значение — вставьте токен и chat_id. В код и в репозиторий они не попадают.
`deploy` напечатает адрес вида `https://vanagstudy-leads.<ваш-поддомен>.workers.dev`.

## 3. Подключить к сайту

В `assets/js/site.js` впишите этот адрес в `LEAD_ENDPOINT`, а в `TELEGRAM_CONTACT` —
свой ник (запасной путь, если Worker недоступен).

Проверка: отправьте заявку с сайта — бот пришлёт сообщение «Новая заявка на диагностику».
